# 🌐 MyFirstAppApplication - Task 1

An introductory Android application showcasing custom UI design, gradient styling, input fields, and interactive components.

---

## 🌟 Key Features

- **Custom UI Components:** Styled input fields, gradient buttons, and visual badge tags.
- **User Interaction:** Demonstrates handling user inputs and button click events.
- **Edge-to-Edge Display:** Modern window insets handling for a full-screen immersive layout.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Android XML, Custom Vector Assets
- **Design System:** Material Design 3

---

## 📂 Project Structure

```text
MyFirstWebApplication/
├── app/
│   └── src/main/
│       ├── java/com/example/myfirstwebapplication/
│       │   └── MainActivity.kt       # Activity logic & view binding
│       └── res/
│           ├── layout/
│           │   └── activity_main.xml # Main UI layout definition
│           └── values/
│               └── strings.xml       # String constants
└── build.gradle.kts
```

---

## 🚀 Getting Started

1. Open Android Studio.
2. Select **Open** and choose the `MyFirstWebApplication` directory.
3. Build & Run the app (`Shift + F10`).

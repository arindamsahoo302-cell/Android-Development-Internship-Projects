## 🚀 How to Run the Projects

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/arindamsahoo302-cell/Android-Development-Internship-Projects.git
   ```

2. **Open in Android Studio:**
   - Launch **Android Studio**.
   - Click **Open** and select the desired project folder (e.g., `AIChatBot`, `LinkdinProfile`, `CollegeAppView`, `SimpleCalculator`, or `MyFirstAppApplication`).
   - Allow Gradle to sync and download dependencies.

3. **Run on Emulator / Device:**
   - Select your Android Emulator or physical device.
   - Click **Run** (`Shift + F10`).

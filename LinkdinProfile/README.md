# 💼 LinkdinProfile App

A modern, responsive native Android application that replicates a **LinkedIn Profile Interface** using Kotlin, XML, ConstraintLayout, and Material Design components.

---

## 📱 Features

- **Profile Header & Cover:** Displays user banner, profile image, name, title, and current organization.
- **Action Buttons:** Quick access buttons for "Open To", "Add Section", "Enhance Profile", and "Resources".
- **Analytics & Resources Section:** Interactive cards showing profile views, impressions, and saved items.
- **About & Experience Sections:** Clean modular card-based layout showcasing bio, experience history, and skills.
- **Edge-to-Edge UI:** Fully compatible with modern Android status bar insets.

---

## 🛠️ Tech Stack & Dependencies

- **Language:** Kotlin
- **UI Framework:** Android XML, ConstraintLayout, CardView, ScrollView
- **Design System:** Material Design 3
- **Build System:** Gradle (Kotlin DSL)
- **Minimum SDK:** API Level 24+ (Android 7.0)

## 🚀 How to Run

1. Open **Android Studio**.
2. Select **Open** and choose the `LinkdinProfile` directory.
3. Sync Gradle and run on an Android Emulator or physical device (`Shift + F10`).

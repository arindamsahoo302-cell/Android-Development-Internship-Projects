# 🧮 SimpleCalculator - Task 2

A modern, responsive native Android Calculator application built with **Kotlin**, **ConstraintLayout**, and **Material Design 3**.

---

## 🌟 Key Features

- **Intuitive UI & Dark Theme:** Custom-styled keypad layout with distinct colors for operator, function, and numeric buttons.
- **Arithmetic Operations:** Quick-access buttons for addition (`+`), subtraction (`-`), multiplication (`×`), and division (`÷`).
- **Parentheses & Double Zero:** Supports brackets (`(`, `)`) for complex expressions and quick entry (`00`).
- **Interactive Display:** Real-time display updates with high contrast text and formatted display screen.
- **Instant Clear (`C`):** Reset display with a single tap.
- **Edge-to-Edge Design:** Implements modern Android WindowInsets for a full-screen, immersive visual experience.

---

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Android XML Layouts, ConstraintLayout
- **Design System:** Material Design 3
- **IDE:** Android Studio
- **Minimum SDK:** Android 7.0 (API Level 24+)
- **Target SDK:** Android 14+ (API Level 34+)

## 🚀 Getting Started

1. Open **Android Studio**.
2. Select **Open** and choose the `SimpleCalculator` directory.
3. Allow Gradle to synchronize dependencies.
4. Select an Android Emulator or connected physical device.
5. Click **Run** (`Shift + F10`) to build and launch the app.
